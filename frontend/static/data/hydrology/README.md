# Hydrographic layer

HydroBASINS level 5 v1c (Europe) and HydroRIVERS v1 (Europe), WWF / HydroSHEDS. Lehner, B. & Grill, G. (2013), Global river hydrography and network routing: baseline data and new approaches to study the world's large river systems, Hydrological Processes, 27(15), 2171–2186, https://doi.org/10.1002/hyp.9740.

Sources: https://www.hydrosheds.org/products/hydrobasins and https://www.hydrosheds.org/products/hydrorivers. Licence, disclaimer and required acknowledgement: HydroSHEDS technical documentation, Appendix A (https://data.hydrosheds.org/file/technical-documentation/HydroSHEDS_TechDoc_v1_4.pdf). This subset and display generalization are TERRA modifications; source input hashes are in network.json. Do not treat the modified subset as an unmodified official product.

95 clipped level-5 basin units, 10,471 river reaches of Strahler order >=4. True geometries/topology, not the challenge package's synthetic polygons. Display polygons and lines are simplified. River links to these coarser basin units are spatial intersections, not direct use of the level-12 ID. Flow orientation is inferred using NEXT_DOWN endpoints and is not verified for terminal/isolated reaches. Northern geometry above 60N uses a coarser DEM. Coastal units may aggregate multiple drainage outlets. Long-term Q is modeled 1971–2000 mean discharge. No current gauge or farm-scale drainage claim. Backend routing is an uncalibrated model of local runoff contribution; particle velocities use assumed cross-sections and are not gauged velocities.
